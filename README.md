# Boo — Fabric mod for Minecraft 1.21.11

A sleepy pixel ghost on your title screen. He's asleep while the menu loads, then wakes up, swoops in a loop and says "welcome back" with your name. He blinks, follows your mouse with his eyes, and waves and says "boo!" when you hover him.

Client-only. Needs Fabric Loader for 1.21.11. No Fabric API needed.

## Get the .jar (built on GitHub, nothing to install)

1. Make a free account at github.com and create a new repository (any name).
2. Click **uploading an existing file** and drag in everything from this folder, including the `.github` folder.
3. Commit. Open the **Actions** tab and wait for the green check (about 3–5 minutes).
4. Click the finished run and download **boo-mod-jar** under Artifacts. Unzip it and use `boo-1.0.0.jar`.

## Install

Put `boo-1.0.0.jar` in `%APPDATA%\.minecraft\mods` and start the Fabric 1.21.11 profile.
